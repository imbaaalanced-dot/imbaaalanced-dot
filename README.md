## 🎮 Mein Hauptprojekt: Denkmal TD2

Ein Open-Source-Tower-Defense-Spiel mit Türmen, Helden, Gegnerwellen und Schauplätzen mit Bezug zu **Kirchende, Westhofen und Hohensyburg**.

- **Spielmodi:** Kampagnen-Level und Denkmal-Ansturm
- **Grafik:** düsterer „Style 2“ mit isometrischer Anmutung
- **Plattform:** Browser; Touch- und Android-Optimierung in Arbeit
- **Technik:** JavaScript, HTML, CSS und automatisierte Tests

> **Entwicklungsstand:** öffentliche Alpha. Ein erfolgreicher CI-Lauf ist nicht gleichbedeutend mit einem bestandenen Langzeittest auf einem echten Android-Gerät.

## 🛠️ Woran ich arbeite
